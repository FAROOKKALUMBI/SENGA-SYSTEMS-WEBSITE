# Senga Systems Website Assets Folder

Place your Figma design images and logos in these directories:

## 📁 Directory Structure & File Names

- `public/assets/logo/`
  - `logo.png` / `logo.svg` - Main Senga Systems logo (used in Navbar & Footer)
  
- `public/assets/images/`
  - `hero-bg.jpg` - Dark hero background with monitor code texture
  - `about-image.jpg` - About Us section image (AI Robot + Engineer)
  
- `public/assets/partners/`
  - `microsoft.svg` - Microsoft partner logo
  - `vmware.svg` - VMware partner logo
  - `cisco.svg` - Cisco partner logo
  - `dell.svg` - Dell Technologies partner logo
  - `aws.svg` - AWS Cloud partner logo
  - `redhat.svg` - RedHat Linux partner logo
